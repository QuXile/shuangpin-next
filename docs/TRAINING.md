# 练习场

[← 文档导航](../README.md#文档导航)

练习场（`/training`）用于自由巩固：不写入课程进度与星级，也不限制目标行数，练到主动退出为止。顶栏「练习」（`Alt+P`）进入。

## 页面结构

- **品牌卡**：练习场标题、固定单行「训练场」键帽、方案按钮（`Alt+1–5`）与「其他方案」（`Alt+6`）。
- 练习场与课程使用同一套多解容错判题；显示主键，合法替代序列也接受。
- **练习设置**：专项 / 文章切换（`Alt+D` / `Alt+A`）、字 / 词模式（`Alt+M`）、可用字词信息与开始按钮（`Enter`）。
- **范围卡**：专项的「出现」「隐藏」；文章练习的输入卡与「隐藏」。

宽屏下两列排布，≤980px 纵向堆叠；练习会话为 1080px 居中窄栏，底部键位图可用 `Ctrl+K` / `Alt+K` 或顶栏按钮显示隐藏。

## 专项练习

「出现」决定练哪些音，「隐藏」决定哪些映射不在字卡与键位图上显示，但判题不变。

- **字 / 词模式**：默认「词」，从统一 Lexicon 抽 2–5 字词；字模式从 Lexicon 单字表抽字。
- **声母 / 韵母**：分组选择，支持全选 / 部分选中；每组有一个「全拼沿用」胶囊，代表与全拼拼写一致的键位集合，按当前方案自动计算、默认开启。
- **零声母**：12 个音节作为独立选择集逐项列出（`零 a`、`零 ai`…含 `零 er`），不受普通韵母勾选限制。
- **已学**：「出现」卡头的「已学」按钮一键选中当前学习进度覆盖的声母、韵母与零声母。
- **隐藏**：候选只包含「出现」中已选中的音；隐藏只影响映射显示，键位仍需按对，同一个字错三次仍会揭示答案，键位图的按下 / 高亮反馈不受影响。

配置页焦点不在输入框 / 按钮时按 `Enter` 可开始。开始后进入无尽练习，批次自动追加，按 `Esc` 退出；会话顶栏显示已练数、正确率、隐藏项数与速度，「重新开始」为 `Alt+R`。

## 文章练习

1. **输入或导入**：粘贴文本，或点击 / 拖拽 `.txt`（UTF-8）；两种模式共用同一份内容。
2. **解析**：只保留汉字；标点、字母、数字、空白、换行都作为断行且不显示，每行最多 5 个汉字；字库外汉字跳过，开始前提示「将练习 N 字 · 跳过 M 字」。
3. **练习与汇总**：按原文顺序逐字练习；隐藏候选为当前方案全部声母 / 韵母 / 零声母；完成后显示字数、正确率、速度、错误次数、用时与错误键位，可再来一遍或换文章。

多音字按练习字库的常用读音处理，不做上下文消歧。

## 配置与预设

- 专项 / 文章页签、字 / 词模式、出现与隐藏范围按方案保存在浏览器本地，刷新或切换方案后恢复；损坏时回退默认全选。
- 课程阶段总结卡的「进入无尽练习」（`Alt+Enter`）会带入当前方案、本课范围与隐藏设置，作为一次性预设，不会自动开始。
- 练习场与课程共用 `data/lexicon/lexicon.json`：约 5,022 个常用字、26,883 条 2–5 字词，按当前范围筛选。
