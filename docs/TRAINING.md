# 练习场

[← 文档导航](../README.md#文档导航)

练习场（`/training`）用于自由巩固：**不写入课程进度与星级**，也不限制目标行数，练到主动退出为止。顶栏「练习」（`Alt+P`）进入。课程内的练习见 [学习指南](LEARNING.md)，快捷键见 [快捷键](SHORTCUTS.md)。

## 页面结构

练习场配置页与学习路线共用同一套卡片语言：

- **上排左卡（品牌卡）**：英文眉题、练习场大标题、单行装饰键帽、5 套课程方案按钮（`Alt+1–5`）与「其他方案」（`Alt+6`）。
- **上排右卡（练习设置）**：专项 / 文章切换（`Alt+D` / `Alt+A`）、字 / 词模式（`Alt+M`）、可用字词信息与开始按钮（`Enter`）。
- **下排两张卡**：专项练习的「出现」与「隐藏」练习范围；文章练习的隐藏范围与文章输入卡。

宽屏下上排两卡比例与学习路线「Hero / 继续学习」一致，桌面撑满高度、范围卡内部滚动；≤980px 按「品牌 → 设置 → 出现 → 隐藏」自然堆叠。练习会话保持 1080px 居中窄栏，底部键位图可由顶栏键盘按钮、`Ctrl+K` 或 `Alt+K` 显示 / 隐藏。

## 方案选择

练习场与学习路线**共享当前方案**（同一个课程 store）：在这里切换方案，回到学习路线也是同一个方案，「出现」范围与隐藏选择按方案分别记住。

- `Alt+1–5` 切换 5 套课程方案；`Alt+6` 聚焦「其他方案」选择器，`←/→` 在方案按钮与选择器之间移动；
- 14 套纯练习方案同样可选，练习场可直接使用其完整键位；
- 纯练习方案不会写回持久化，刷新后回到上次保存的课程方案（与学习路线预览行为一致）。

## 专项练习

「出现」决定练哪些音，「隐藏」决定哪些映射不在字卡与键位图上显示，但判题不变。

### 出现范围

- **字 / 词模式**：默认「词」；字模式从单字库抽字，词模式从公共词库抽 2–5 字词。`Alt+M` 切换。
- **声母 / 韵母分组**：每组有全选勾选框（支持部分选中）与「全拼沿用」胶囊。胶囊只显示四个字，不展开内部键位，算作该组的一个可选项，参与全选 / 全清；它代表的集合按当前方案自动计算与全拼拼写一致的键位，切换方案自动重算，默认开启。
- **零声母独立选择集**：12 个零声母音节逐项列出（`零 a`、`零 ai`…含 `零 er`），不受普通韵母勾选限制。
- **已学**：出现卡头的「已学」按钮一键选中当前学习进度已覆盖的声母、韵母与零声母（全拼沿用 + 已通过课程 focus）。
- 过滤规则：普通音节必须同时命中所选声母与韵母；零声母音节只按零声母集合判断。

### 隐藏范围

- 专项中隐藏候选**只列出「出现」中已选中的声母 / 韵母 / 零声母音节**，出现范围变化时自动收缩；
- 提示隐藏只影响显示：被隐藏的音节在字卡与键位图上不显示映射文字，但键位仍需按对、判题不变；同一个字错三次仍会揭示答案；
- 键位图的 hover / pressed / focus 反馈独立于映射文字，隐藏映射或全遮挡时仍然保留。

### 开始与进行中

- 配置页焦点不在输入框 / 按钮时按 `Enter` 可直接开始当前页签的练习；
- 开始后进入**无尽练习**：没有目标行数，批次自动追加，直到按 `Esc` 退出；
- 会话顶栏左侧为退出（`Esc`）/ 重新开始（`Alt+R`），中间实时显示已练字 / 词数、正确率、隐藏项数与速度；
- 底部键位图实时高亮，包含零声母行；隐藏项的作用同上。

## 文章练习

用于把一段真实文本练成肌肉记忆：

1. **输入或导入**：输入模式直接粘贴文本；导入模式点击或拖拽 `.txt` 文件（按 UTF-8 读取）。两种模式共用同一份文章内容与解析结果。
2. **解析规则**：只保留汉字；任何非汉字（标点、引号、括号、字母、数字、空白、换行）都不显示，并作为断行；连续分隔合并；每行最多 5 个汉字（短行保留）。字库外汉字会被跳过，开始前在输入卡下方提示「将练习 N 字 · 跳过 M 字」。
3. **隐藏范围**：文章没有「出现」筛选，隐藏候选为当前方案的全部声母 / 韵母 / 零声母（同样提供「全拼沿用」胶囊）。
4. **练习与汇总**：按原文顺序逐字练习；完成后显示字数、正确率、速度、错误次数、用时以及错误键位，可「再来一遍」或「换文章」。

多音字按练习字库的常用读音处理，不做上下文消歧。

## 从课程进入无尽练习

课程阶段总结卡上的「进入无尽练习」（`Alt+Enter`）会把当前方案、本课已学范围与当前阶段对应的隐藏档位作为一次性预设带入练习场，但**不会自动开始**，可在练习场确认设置后手动开始。

- 专项 / 文章页签与字 / 词模式按当前方案保存在浏览器本地，刷新或切换方案后恢复；
- 预设只应用一次，后续切换方案或重新进入练习场不会重复套用。

## 数据与持久化

- 练习字库为 `data/training/bank.json`（约 5,002 个常用字，约 0.8MB）；词语来自公共词库（10,000 词），不重复存储；
- 练习场配置按方案保存在 `localStorage`，键名与字段说明见 [架构说明](ARCHITECTURE.md#10-web-应用层)；损坏或缺失时回退到默认全选；
- 学习进度、星级不受练习场影响。

## 音效与回顶

键盘输入、错误与完成都有 Web Audio 合成音效，默认开启，可用顶栏喇叭按钮或 `Alt+B` 开关；地图页滚动超过 320px 后可用 `Home` 回到顶部。练习场页面本身不做回顶按钮。
