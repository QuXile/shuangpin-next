# 使用说明

[← 文档导航](../README.md#文档导航)

在线使用、离线包、学习路线、练习场与快捷键都在这一篇里；开发、发布与数据维护见 [贡献指南](CONTRIBUTING.md)。

## 在线使用

直接访问 <https://quxile.github.io/shuangpin-next/>，无需安装、注册或联网登录。支持现代 Chrome、Edge、Firefox、Safari 桌面版；浏览器过旧时部分选中态 / 主题效果可能缺失。

## 本地数据

以下内容只保存在浏览器本地，不会上传到服务器：

- 主题偏好、当前双拼方案、音效开关；
- 每套方案各自的学习进度、解锁全部课程标记；
- 练习场的出现 / 隐藏范围、专项 / 文章页签；
- 学习地图的滚动位置，以及从课程总结卡带入的一次性练习预设。

清除站点数据、换浏览器、换设备或使用无痕模式都会导致这些内容不可用或不迁移。

## 下载静态包，离线使用

在 [GitHub Releases](https://github.com/QuXile/shuangpin-next/releases) 下载 `shuangpin-next-<版本>-static.zip`，解压后**不要双击 `index.html`**，用包内启动器：

```bash
cd shuangpin-next-*-static
python start.py
```

启动器会打印本地地址并自动打开浏览器；只需要 Python 3，无需第三方包或 Node.js。可选参数：

```bash
python start.py --port 8080     # 指定端口，默认 8080，被占用时向后尝试最多 20 个端口
python start.py --no-browser    # 不自动打开浏览器
python start.py --root <目录>   # 指定静态目录，默认 start.py 所在目录
```

也可以用任意静态文件服务器，例如 `python -m http.server 8080`、`npx serve .`，然后访问终端显示的 `http://127.0.0.1:<端口>/`。

静态包使用 hash 路由（地址栏形如 `#/training`），不依赖服务器 SPA 重写，可放在任意子目录，也不连接外网。包内包含 `start.py`、`LICENSE` 与 `使用说明.txt`，发布页另附 `SHA256SUMS` 供校验；更新时整个目录替换即可。

## 常见问题

**打开后提示「数据加载失败」**
多为直接双击 `index.html`，浏览器禁止读取同目录 JSON。请用 `python start.py` 或任意静态服务器，并确认解压完整、数据目录存在。

**静态包地址为什么有 `#`？**
静态包使用 hash 路由，避免依赖服务器 SPA 回退；在线站点使用普通路径。

**学习进度丢了 / 换方案后进度不见了**
进度按方案保存在浏览器本地，切换方案会加载对应进度；清除站点数据、无痕模式或换设备都会导致原进度不可见。

**音效没有声音**
浏览器要求先与页面交互才能播放音频；检查顶栏喇叭按钮或 `Alt+B` 是否关闭、系统音量与站点静音即可。

**在手机上能用吗？**
移动端可浏览和操作界面，键位图可点击输入；练习主要按物理键盘设计，推荐桌面浏览器。

**支持哪些方案？**
应用自带 19 套双拼方案（5 套定制课程 + 14 套自动生成课程），与系统输入法无关；只想自由练习时可用练习场。

**如何切换到深色主题？**
默认跟随系统主题；点击顶栏主题按钮或按 `Alt+T` 手动切换，选择会保存在本地。

## 学习路线与课程

课程假定你已经会拼音的声母、韵母与声调，只教双拼的键位差异。自由练习见[练习场](USAGE.md#练习场)，按键见[快捷键](USAGE.md#快捷键)。

### 学习路线

19 套课程全部可进入学习路线：5 套定制完整课程（小鹤、微软、自然码、拼音加加、搜狗），14 套按方案数据自动生成的通用课程。每套 40–64 课、10–13 章，均按「入门 → 新课 → 复习 → 期中 / 综合 → 通关」推进。

- **一课一键**：每次只引入新的声母或韵母，题目只包含已学内容；定制课程会把同键双韵（如 `ia/ua`、`ong/iong`、`ue/ve`）合并成一课，通用课程按单个原子逐课教学。
- **与全拼一致的键位**直接视为已会（free 原子），不单独出课；课程只教需要改造的映射（learn 原子）。
- **知识范围**：只有声母 / 韵母阻塞选词；章末复习只覆盖本章刚学的键位，期中 / 综合 / 期末才复用累计已学范围；复习课不引入新键位。
- **零声母**：定制课程把当前方案中与全拼不一致、需要记忆的零声母音节集中在一课内教学（其余归入「全拼沿用」）；通用课程逐个零声音节成课，统一显示为「零 ai」这类形式。
- **通用课程结构**：内容章按「单韵母 → 单声母 → 复合声母 → 前响 / 中响 / 后响复韵母 → 基本后鼻 / 基本前鼻 → 带介前鼻 / 后鼻韵母 → 零声母」排列；每章末复习，内容章之间按前后新课数均衡插入「期中」，最终章为综合练习 → 速度练习 → 最终考核。推荐码与兼容编码信息写进对应原子课的技巧里。

### 课型与练习阶段

除入门课外，进入课程先看教学页，再按课型练习。**单位统一为词**：单字阶段 1 个字算 1 个词；每课最后一场都是无提示考核。

| 课型 | 阶段与提示档位 | 最低完成量 |
|---|---|---|
| 新课 | 单字完整提示 → 词语部分提示 → 无提示考核 | 15 → 15 → 25 词 |
| 复习（含家族复习 / 期中 / 综合） | 无提示练习 / 考核 | 50 词 |
| 通关 | 无提示考核 | 100 词 |
| 入门 | 独立入门课 + 固定试打「双拼」 | 完成试打即通过 |

最低词数由课程数据 `stageMinWords` 给出（缺省使用课型默认值）。单字 / 词语阶段只要求完成词数；无提示考核还需达到本课通过标准，**达标即自动记录通过**，不需要在总结卡上再点完成。

每阶段结束出现总结卡：达标为绿色、未达标为红色，展示正确率、速度、错误次数、用时、错误键位与评分规则，可重练。已完成的单字 / 词语阶段会被记住，来回切换阶段不需要重做。

### 评分与星级

- **1 星即最低通过标准**；★★ ≥90%，★★★ ≥95% 且本阶段未揭示答案。
- 正确率 = 正确字数 ÷（正确字数 + 错误次数）；速度按正确字数 ÷ 用时换算为 WPM。
- 同一个字累计错满 3 次会直接揭示正确键位；被揭示过的阶段不能拿 ★★★。
- 星级、门槛与教学页「评分标准」来自同一份数据，不会出现页面说一套、判定用另一套。

| 课程 / 考核 | ★ | ★★ | ★★★ |
|---|---|---|---|
| 新课，25 词 | 正确率 ≥85% | ≥90% | ≥95% 且未揭示 |
| 复习 / 期中混合 / 综合混合，50 词 | 正确率 ≥85%，速度 ≥45 WPM | ≥90%，速度 ≥45 | ≥95%，速度 ≥45 且未揭示 |
| 期中 / 综合速度，50 词 | 正确率 ≥85%，速度 ≥45 | ≥85%，速度 ≥60 | ≥85%，速度 ≥75 |
| 通关考核，100 词 | 正确率 ≥85%，速度 ≥45 | ≥90%，速度 ≥60 | ≥95%，速度 ≥75 且未揭示 |
| 入门课 | 完成试打 | 同 ★ | 完成试打即记 ★★★ |

已通过的课程可重练；通过状态、星级与最佳正确率都取历史最优，尝试次数累加。

### 进度与解锁

- 课程按顺序解锁：前一课通过后解锁下一课；已通过课程可重练。
- 「解锁全部课程」`Alt+U` 解除全部顺序限制并持久化，再次触发变为「恢复锁定」。
- 「清除进度」`Alt+C` 只清当前方案的学习记录，不影响解锁标记。
- 进度按方案分开保存；切换方案会加载对应进度。

### 教学页

- **课程范围**：本课要学的键位知识点（新 / 含标记）、对应键位与映射数量。
- **示例**：按本课 focus 原子展开所有相关音节，每个音节一张高频代表字卡片；范围大时列表可滚动。
- **记忆锚点**：只在新课（drill）出现，复习 / 考核课不显示；有改造键位时逐键展示记忆法与高频字；零声母整表课没有改造键位，改用一条「N 音映射」汇总行（N 为本课需要记忆的零声母数）。
- **本课技巧**：定制课程展示人工撰写的提示；通用课程展示推荐码 / 兼容编码说明。
- **评分标准**：与判定同源的 1–3 星门槛。

### 入门课

由当前方案数据自动生成：拼音基础 → 方案选择指南 → 声母 → 韵母 → 零声母 → 多键（仅当方案有多键映射）→ 推荐码 / 兼容编码（仅当方案有这类编码）→ 工具说明 →「试一试」页固定试打「双拼」。键位、示例与试打词都由方案引擎和统一词表生成，不写死方案名；完成试打后写入通过记录并统一记 ★★★。

### 输入与错误处理

- 合法输入键为小写字母与 `;`；输入完当前字后整字判题，接受方案的全部合法键序列（多解容错）。
- 判错后保留红色错误输入并锁定该字，继续按字母无反应；退格逐键撤销并解除错误。
- 空格或 `Enter` 一次清空当前字的错误输入；`Enter` 清空优先于主按钮。
- 同一个字错满 3 次揭示目标键位；退格与清空也用于练习场的自由练习。

### 学习地图

- **Hero**：右侧键帽由当前方案名称逐字取拼音再映射成按键，随机散落；可用物理键盘或点击键位图按顺序输入，答对变绿，部分答对后闲置 5 秒会重新散落。
- **方案选择**：`Alt+1–5` 切换主要方案，`Alt+6` 打开「更多方案」，`Alt+S` 聚焦方案选择器，`←` / `→` 在两者之间移动。
- **继续学习与路线**：继续学习卡显示当前课并可开始；路线按章节分组、两列课程卡；`↑` / `↓` 选课、`Enter` 开始，已通过课程显示星级。
- **滚动与回顶**：滚动位置按方案记忆；滚动超过 320px 后右下角出现「回到顶部」按钮，快捷键 `Home`。
- **学习进度卡**：显示完成百分比、通过课程数、章节数与词库规模，卡头为「清除进度 / 解锁全部课程」。

## 练习场

练习场 `/training` 用于自由巩固：不写入课程进度与星级，可随时退出。顶栏「练习」按钮或 `Alt+P` 进入；与课程共用同一套多解容错判题和底部键位图。

### 页面结构

- **品牌卡**：练习场标题与固定单行键帽；方案按钮 `Alt+1–5`，「更多方案」`Alt+6`，`←` / `→` 在两者之间移动。
- **练习设置卡**：专项 / 文章切换 `Alt+D` / `Alt+A`；显示可用词数量或文章字数、跳过字数；`Enter` 开始练习（焦点不在交互元素上时）。
- **出现卡**：本局练习范围，即哪些声母、韵母、零声母参与出题。
- **隐藏卡**：练习时哪些映射不在字卡与底部键位图上显示，不影响判题。
- **底部键位图**：配置页也显示，可用 `Ctrl+K` / `Alt+K` 或顶栏键盘按钮隐藏；点击键位与物理键盘走同一输入管线。

宽屏下左右两列排布，窄屏纵向堆叠；练习会话为居中窄栏。

### 专项练习

从统一词库中抽取符合「出现」范围的 2–5 字词语，进入无尽练习：每批 10 个词，完成后自动追加下一批，直到按 `Esc` 退出。

#### 出现范围

- **声母 / 韵母 / 零声母** 三组独立选择，每组支持全选、部分选中与单项勾选；组头显示「已选 A/B」。
- **全拼沿用**：每组开头的胶囊代表与全拼拼写完全一致的键位集合，按当前方案自动计算，默认开启。胶囊与普通 chip 一起参与组全选 / 部分选中计数；点击胶囊可整组开关这些公共键位。
- **零声母**：独立列出（`零 a`、`零 ang`…），只包含当前方案中与全拼不一致、需要记忆的音节；与全拼一致的归入「全拼沿用」胶囊。零声母不受普通韵母勾选影响，当前方案没有的零声母不出现。
- **已学**：卡头的「已学」按钮按当前学习进度，一键选中已通过课程覆盖的声母、韵母与零声母，并显示「当前进度 N/M 课」。
- **键位图联动**：键位图实时高亮当前「出现范围」；点击声母 / 韵母 / 零声母映射可增删该范围（点键帽本身仍是键盘输入）。兼容映射不可独立选择，只有构成音节的声母与韵母都在范围内时才会强调。

#### 隐藏映射

- 候选只包含「出现」中已选中的普通键位（全拼沿用仍以胶囊形式出现），未选中的音不会出现在隐藏卡里。
- 会话开始后隐藏项冻结，会话中再改设置不会影响本局；会话顶栏显示「隐藏 N 项」，悬停可看具体列表。
- 任意隐藏项生效时，底部键位图进入无提示模式：隐藏全部映射、图例、零声母与兼容编码，只保留按键与按下反馈；字卡上也隐藏对应映射，判题不变。
- 同一个字错满 3 次仍会揭示正确键位。

#### 会话顶栏

显示「已练 N 词」「正确率」「隐藏 N 项」「速度 WPM」；左侧「退出 `Esc`」与「重新开始 `Alt+R`」。正确率与速度在完成第一个字后才显示。

### 文章练习

1. **输入或导入**：粘贴文本，或点击 / 拖拽 `.txt` 文件（UTF-8）；「输入」与「导入」两个页签共用同一份文章内容，导入后仍可切回输入继续编辑。
2. **解析**：只保留汉字；标点、字母、数字、空白与换行都作为断行且不显示，每行最多 5 个汉字；词库外的汉字跳过，开始前提示「将练习 N 字 · 跳过 M 字」。
3. **练习**：按原文顺序逐字练习，无提示；隐藏候选为当前方案全部普通声母 / 韵母 / 零声母（全拼沿用同样以胶囊开关）。
4. **汇总**：完成后显示字数、正确率、速度、错误次数、用时与错误键位排行，可「再来一遍」或「换文章」。

多音字按词库的常用读音处理，不结合上下文消歧。

### 配置与预设

- 专项 / 文章页签、出现范围、专项隐藏与文章隐藏 **按方案** 保存在浏览器本地；刷新、切换方案后自动恢复，损坏或缺失时回退为默认全选。
- 课程阶段总结卡的「进入无尽练习」（`Alt+Enter`）会把手头本课的方案、已学范围、阶段隐藏设置作为一次性预设带入练习场，并自动切到专项练习；预设读取后立即清除，不会在刷新后覆盖后续修改。
- 若带入时练习场停留在另一个方案，会先切回预设方案再应用。
- 练习场与课程共用同一份统一词库（`lexicon`）：29,660 条词语与 3,009 个字符，字符按音节保留常用字用于组卷与文章映射。

## 快捷键

所有页面级快捷键统一由输入管线注册：输入框、文本域、下拉框聚焦时不会触发页面快捷键，只有 `Alt+T`、`Alt+B`、`Ctrl+K` / `Alt+K` 这类全局操作例外。按 `?` 打开应用内快捷键面板，`Esc` 或 `?` 关闭；面板打开时 `Tab` 在面板内移动。

### 全局

| 快捷键 | 作用 |
|---|---|
| `Alt+H` | 回到课程路线（学习地图） |
| `Alt+P` | 进入练习场 |
| `Alt+T` | 切换亮色 / 暗色主题 |
| `Alt+B` | 开启 / 关闭音效 |
| `Home` | 回到页面顶部；学习地图滚动超过 320px 后可用 |
| `Ctrl+K` / `Alt+K` | 显示 / 隐藏底部键位图，仅当前页面支持底部键位图时生效 |
| `?` | 打开 / 关闭快捷键面板 |
| `Esc` | 关闭快捷键面板；或执行当前页面的一级返回 |

### 学习路线

| 快捷键 | 作用 |
|---|---|
| `Alt+S` | 聚焦当前双拼方案选择器 |
| `Alt+1` – `Alt+5` | 切换主要双拼方案（按方案列表顺序） |
| `Alt+6` | 打开「更多方案」选择器 |
| `←` / `→` | 在方案按钮与「更多方案」下拉之间移动 |
| `↑` / `↓` | 在学习路线课程卡之间移动；焦点在下拉框内时用于切换选项 |
| `Enter` | 开始当前课程 |
| `Alt+U` | 解锁全部课程 / 恢复锁定 |
| `Alt+C` | 清除当前方案的学习进度 |

### 教学页与入门课

| 快捷键 | 作用 |
|---|---|
| `Enter` | 教学页开始练习；入门课下一页 / 完成试打；有错误输入时优先清空 |
| `Alt+←` | 入门课返回上一页 |
| `Space` | 有错误输入时清空当前字（入门课试打页、练习页） |
| `Esc` | 返回学习路线 |

### 练习 / 考核

| 快捷键 | 作用 |
|---|---|
| `Enter` | 主操作：开始练习 / 下一阶段 / 完成本课；有错误输入时优先清空当前字 |
| `Alt+Enter` | 阶段总结卡出现后，带本课范围进入无尽练习（跳转练习场） |
| `Alt+←` | 上一阶段 |
| `Alt+R` | 重新开始当前阶段 |
| `Backspace` | 退格撤销当前输入 |
| `Space` | 清空当前字的错误输入 |
| `Esc` | 上一阶段；已在教学页时返回学习路线 |

练习中字母键与 `;` 直接输入；判错后该字被锁定，退格或清空可解除。达标后主按钮变为「下一阶段 / 完成本课」，最后一场考核达标会自动记录成绩。

### 练习场

配置页：

| 快捷键 | 作用 |
|---|---|
| `Alt+D` | 切换到专项练习 |
| `Alt+A` | 切换到文章练习 |
| `Alt+1` – `Alt+5` | 切换主要双拼方案 |
| `Alt+6` | 打开「更多方案」选择器 |
| `←` / `→` | 在方案按钮与「更多方案」下拉之间移动 |
| `Enter` | 开始练习（焦点不在按钮 / 输入框等交互元素上时） |

练习会话中：

| 快捷键 | 作用 |
|---|---|
| `Esc` | 退出当前练习会话 |
| `Alt+R` | 重新开始当前会话 |
| `Space` / `Enter` | 清空当前字的错误输入 |
| `Backspace` | 退格撤销当前输入 |
| 字母 / `;` | 输入按键，与课程练习同一套多解容错判题 |

### 通用

| 快捷键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 按顺序聚焦下一个 / 上一个控件 |
| `Enter` | 激活当前按钮 / 确认 |
| `Space` | 激活当前按钮 / 切换勾选 |

> 快捷键面板的展示数据在 `apps/web/src/lib/shortcuts.ts`，实际绑定由各页面的 `useGlobalKeys` 与 `useKeyInput` 负责；两者不一致时以实际绑定与本页为准。
