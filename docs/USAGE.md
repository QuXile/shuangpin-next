# 使用说明

[← 文档导航](../README.md#文档导航)

本页说明如何在线使用、离线使用、数据保存在哪里，以及常见问题。想先了解产品内容，请看 [README](../README.md)；学习流程见 [学习指南](LEARNING.md)，练习场用法见 [练习场](TRAINING.md)。

## 在线使用

直接访问 <https://quxile.github.io/shuangpin-next/> 即可，无需安装或注册。

支持现代 Chrome、Edge、Firefox、Safari 桌面版。界面使用 CSS `color-mix`、`:has` 等新特性，过旧的浏览器会缺少部分选中态 / 主题效果；如遇到异常，请先升级浏览器。

## 本地数据与隐私

所有数据都保存在你自己的浏览器中，不会上传到任何服务器：

| 数据 | 说明 |
|---|---|
| 主题 | 跟随系统或手动选择，记住最后一次选择 |
| 当前双拼方案 | 全站共享；纯练习方案的预览状态不持久化，刷新后回到上次保存的课程方案 |
| 学习进度 | 按方案分开保存（通过状态、星级、最佳正确率、尝试次数），清除进度只影响当前方案 |
| 解锁全部课程 | 标记持久化；「恢复锁定」会移除该标记 |
| 音效开关 | 默认开启，记住最后一次开关状态 |
| 练习场配置 | 按方案保存出现范围、隐藏选择、字 / 词模式与专项 / 文章页签 |
| 学习地图滚动位置 | 按方案记忆，仅当前浏览器会话内有效 |

清除浏览器站点数据、换浏览器或无痕模式会导致这些内容不再可用；无痕模式下本次会话仍可正常使用，但关闭后不保留。

## 下载静态包（离线使用）

在 [GitHub Releases](https://github.com/QuXile/shuangpin-next/releases) 下载 `shuangpin-next-<版本>-static.zip`，解压后**不要双击 `index.html`**，而是用包内启动器：

```bash
cd shuangpin-next-*-static
python start.py
```

启动器会打印可点击的本地地址、数据目录与停止方式，并自动打开浏览器。可选参数：

```bash
python start.py --port 8080     # 指定端口（默认 8080，占用时自动向后尝试）
python start.py --no-browser    # 不自动打开浏览器
python start.py --root <目录>   # 指定静态目录（默认是 start.py 所在目录）
```

**依赖**：只需要 Python 3，不需要安装任何第三方 Python 包，也不需要 Node.js。

如果不想用启动器，任意静态文件服务器也可以，例如：

```bash
python -m http.server 8080
npx serve .
```

启动后访问终端显示的 `http://127.0.0.1:<端口>/`。

注意事项：

- 静态包使用 **hash 路由**（地址栏会出现 `#/training` 等），不依赖服务器 SPA 重写规则，也可以放在任意子目录；
- 静态包不连接外网，数据目录完整即可离线使用；
- 包内包含 `LICENSE`（GPL-3.0-only）与 `使用说明.txt`；发布页同时提供 `SHA256SUMS` 用于校验下载文件；
- 更新静态包时请整个目录替换；启动器会禁用缓存，避免继续使用旧资源。

## 常见问题

**打开后提示「数据加载失败」**
最常见的原因是直接用 `file://` 双击打开了 `index.html`，浏览器不允许本地页面读取同目录 JSON。请改用 `python start.py`，或通过任意静态服务器访问。用启动器仍失败时，确认解压完整（`data/` 目录存在）。

**为什么静态包地址里有 `#`？**
静态包使用 hash 路由，避免依赖服务器配置 SPA 回退；在线站点使用普通路径路由。

**学习进度丢了 / 换方案后进度不见了**
进度按方案分别保存在浏览器本地；切换方案会加载该方案自己的进度。清除站点数据、无痕模式、换浏览器或换设备都会导致原进度不可见。

**音效没有声音**
浏览器要求用户先与页面交互才能播放音频，首次点击或按键后才会解锁音频；也可以检查顶栏喇叭按钮或 `Alt+B` 是否被关闭、系统音量与站点静音设置。

**在手机上能用吗？**
移动端可以浏览与操作界面（布局、顶栏与卡片已适配窄屏），练习主要按物理键盘设计（底部键位图 / 键帽也可以点击输入），体验推荐桌面浏览器。想离线使用请按上面的方式启动静态包。

**支持哪些输入法 / 方案？**
应用自带 19 套双拼方案，练习时直接按双拼按键输入，与系统输入法无关。只想练习、不想学完整课程时，练习场支持任意方案。

## 系统要求

| 场景 | 要求 |
|---|---|
| 在线使用 | 现代桌面浏览器（Chrome / Edge / Firefox / Safari），无需安装 |
| 离线静态包 | Python 3（推荐启动器），或任意静态文件服务器 |
| 本地开发 / 自行构建 | Node.js ≥ 24、pnpm 11.28.5，详见 [贡献指南](CONTRIBUTING.md) |
| 自行打包发布 | 构建环境另见 [发布说明](RELEASE.md) |
