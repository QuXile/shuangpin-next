# 使用说明

[← 文档导航](../README.md#文档导航)

在线使用、离线包、学习路线、课程、练习场与快捷键。开发与数据维护见[贡献指南](CONTRIBUTING.md)。

## 在线使用与本地数据

直接访问 <https://quxile.github.io/shuangpin-next/>。主题、方案、音效、学习进度、练习场范围与滚动位置只保存在浏览器本地；清除站点数据、换浏览器或换设备后不会迁移。

## 离线静态包

从 [GitHub Releases](https://github.com/QuXile/shuangpin-next/releases) 下载 `shuangpin-next-<版本>-static.zip`，解压后运行包内启动器：

```bash
cd shuangpin-next-*-static
python start.py
```

`start.py` 需要 Python 3，打印本地地址并自动打开浏览器；可选 `--port`、`--no-browser`、`--root`。静态包使用 hash 路由（地址形如 `#/training`），可放在任意子目录，不依赖服务器重写，也不连接外网。也可以用任意静态文件服务器，但**不要直接双击 `index.html`**：浏览器会阻止本地页面读取同目录 JSON。

## 学习路线与课程

课程假定你已会拼音的声母、韵母与声调，只教双拼键位差异。19 套方案全部有路线：5 套定制课程（小鹤、微软、自然码、拼音加加、搜狗）与 14 套按方案数据生成的通用课程。每套 40–64 课、10–13 章，按「入门 → 新课 → 复习 → 期中 / 综合 → 通关」推进。

- **一课一键**：新课每次引入一个声母或韵母，题目只包含已学内容；与全拼一致的键位（free 原子）直接视为已会，不单独出课。
- **范围**：只有声母 / 韵母阻塞选词；章末复习只覆盖本章键位，期中 / 综合 / 期末复用累计已学范围。
- **零声母**：定制课程把需要记忆的零声母集中在少数课内；通用课程按零声音节逐课教学，统一显示为「零 ai」这类形式。
- **推荐码 / 兼容编码**：按“课程范围首次包含完整音节”的位置出现在对应课的教学页技巧中；没有对应课程时放在第一节正式练习课。

### 课型与练习阶段

除入门课外，进入课程先看教学页，再按课型练习。单字阶段 1 个字算 1 个词；每课最后一场都是无提示考核。

| 课型 | 阶段与提示档位 | 最低完成量 |
|---|---|---|
| 新课 | 单字完整提示 → 词语部分提示 → 无提示考核 | 15 → 15 → 25 词 |
| 复习（含家族复习 / 期中 / 综合） | 无提示练习 / 考核 | 50 词 |
| 通关 | 无提示考核 | 100 词 |
| 入门 | 入门课 + 固定试打「双拼」 | 完成试打即通过 |

最低词数由课型默认值给出。无提示考核需达到本课评分标准，达标即自动记录通过。每阶段结束出现总结卡：正确率、速度、错误次数、用时、评分规则与错误键位排行；错误键位会标注应按的键、对应声母 / 韵母 / 零声母胶囊与按成的键；同一应按音的多个按错键会合并到一行；错误键位区在内容超出时独立滚动，未超出或已到边界时继续带动外层，可重练；已完成的单字 / 词语阶段会被记住。

### 评分与星级

- 正确率 = 正确字数 ÷（正确字数 + 错误次数）；速度按正确字数 ÷ 用时换算为 WPM；
- 同一个字累计错满 3 次会揭示正确键位，被揭示过的阶段不能拿 ★★★；
- 练习顶栏的正确率 / 速度只显示数值和对应星级，不展示档位区间；
- 星级、门槛与教学页「评分标准」来自同一份数据。

| 课程 / 考核 | ★ | ★★ | ★★★ |
|---|---|---|---|
| 新课，25 词 | 正确率 ≥85% | ≥90% | ≥95% 且未揭示 |
| 复习 / 期中混合 / 综合混合，50 词 | ≥85%，≥45 WPM | ≥90%，≥45 | ≥95%，≥45 且未揭示 |
| 期中 / 综合速度，50 词 | ≥85%，≥45 | ≥85%，≥60 | ≥85%，≥75 |
| 通关考核，100 词 | ≥85%，≥45 | ≥90%，≥60 | ≥95%，≥75 且未揭示 |
| 入门课 | 完成试打 | 同 ★ | 完成试打记 ★★★ |

已通过的课程可重练；星级与最佳正确率取历史最优，尝试次数累加。

### 进度与解锁

课程按顺序解锁：前一课通过后解锁下一课。`Alt+U` 解锁全部课程 / 恢复锁定；`Alt+C` 只清当前方案的学习记录，并把章节展开状态与“已自动收起”标记一起重置；进度按方案分开保存。

### 教学页

- **课程范围**：本课键位知识点（新 / 含标记）与映射数量；
- **示例**：按本课 focus 原子展开音节，每个音节一张高频代表字卡片；
- **记忆锚点**：只在新课出现；声母与同键韵母、韵母与同键声母组合展示记忆法和高频字；零声母用一条「N 音映射」汇总；
- **本课技巧**：人工撰写的提示与运行时生成的推荐码 / 兼容码说明；
- **评分标准**：与判定同源的 1–3 星门槛。

### 入门课

按当前方案自动生成：拼音基础 → 方案选择指南 → 声母 → 韵母 → 零声母 → 多键（若有多键映射）→ 推荐码 / 兼容编码（若有）→ 工具说明 →「试一试」页固定试打「双拼」。键位、示例与试打词都由方案引擎和词表生成；完成试打记 ★★★。

### 输入与错误处理

合法输入为小写字母与 `;`；输入完当前字后整字判题，接受方案的全部合法键序列。判错后保留红色输入并锁定该字，退格撤销并解除错误；`Space` / `Enter` 清空当前字的错误输入。错满 3 次揭示目标键位。

### 学习地图

- **Hero**：右侧键帽由方案名称逐字映射；可用物理键盘或点击键位图按顺序输入，答对变绿，部分答对后闲置 5 秒重新散落；
- **方案选择**：`Alt+1–5` 切换主要方案，`Alt+6` 打开「更多方案」，`Alt+S` 聚焦选择器，`←` / `→` 移动；
- **继续学习与路线**：继续学习卡显示当前课并可开始；`Alt+L` 定位当前课程；路线按章节分组、两列课程卡；`↑` / `↓` 选课、`Enter` 开始，已通过课程显示星级；
- **章节折叠**：点击章节头展开或收起该章课程，带动效并记录状态；整章第一次学完会自动收起一次，之后保留你的展开 / 收起选择；`Alt+L` 定位当前课时会自动展开所在章节，键盘选课只经过可见课程；
- **滚动与回顶**：滚动位置按方案记忆；滚动超过 320px 后出现「回到顶部」按钮，快捷键 `Home`；
- **学习进度卡**：显示完成百分比、通过课程数、章节数与平均星级；卡头为「清除进度 / 解锁全部课程」。

## 练习场

练习场 `/training` 用于自由巩固，不写入课程进度与星级。顶栏「练习」或 `Alt+P` 进入；与课程共用多解容错判题与底部键位图。

### 页面结构

- **品牌卡**：练习场标题与固定单行键帽；方案按钮 `Alt+1–5`，「更多方案」`Alt+6`；
- **练习设置卡**：专项 / 文章切换 `Alt+D` / `Alt+A`，专项时同一行右侧显示当前进度与「已学」；显示可用词数量或文章字数、跳过字数；`Enter` 开始练习；
- **出现卡**：本局练习范围（声母、韵母、零声母），右上角「已选 x / 清空」；
- **焦点卡**：仅专项显示；每个词至少包含一个选中焦点，空 = 不限，右上角「已选 x / 清空」；
- **隐藏卡**：练习时哪些映射以「?」占位显示，不影响判题，右上角「已选 x / 清空」；
- **底部键位图**：`Ctrl+K` / `Alt+K` 或顶栏键盘按钮隐藏；点击键位与物理键盘走同一输入管线。

专项宽屏为「出现 / 焦点 / 隐藏」三栏，文章为「输入 / 隐藏」两栏；窄屏纵向堆叠；练习会话为居中窄栏。

### 专项练习

从词表抽取符合「出现」范围的 2–5 字词语，进入练习：每批 10 个词，完成后自动追加，`Esc` 退出。

- **出现范围**：声母 / 韵母 / 零声母三组独立选择，支持全选、部分选中与单项勾选；组头显示「已选 A/B」；新增普通原子时（单项勾选、组内全选、「已学」），会自动同步选中到焦点与专项隐藏（全拼沿用胶囊除外）；移除项自动从二者收缩；首次进入的默认全选不联动（焦点与隐藏保持为空）；
- **焦点**：只在当前出现范围内选择；选中后每个词至少包含一个焦点原子，空集合表示不限；课程「进入练习」会自动带入本课焦点，可手动清空；
- **全拼沿用**：每组开头的胶囊代表与全拼拼写一致的键位集合，按方案自动计算，默认开启；
- **零声母**：需要记忆的音节独立列出（`零 a`、`零 ang`…）；与全拼一致的零声母归入「全拼沿用」胶囊；
- **已学**：位于练习设置行右侧；把出现范围对齐到全部全拼沿用 + 已通过课程覆盖的键位（含零声母）：移除已选但未学的原子，补上已学但未选的原子；新增的普通原子同样按出现范围统一口径同步到焦点与专项隐藏，移除项自动从二者收缩。旁边显示「当前进度 N/M 课」；当前出现范围已经等于已学范围时，按钮置灰不可点击；
- **键位图联动**：实时高亮出现范围；点击映射可增删范围。兼容编码不可独立选择，构成音节的声母与韵母都在范围内时才强调；
- **隐藏映射**：候选只包含已选中的普通键位；会话开始后隐藏项冻结，顶栏显示「隐藏 N 项」；任意隐藏项生效时，底部键位图隐藏全部映射与图例，字卡上标答键帽以「?」占位、拼音始终显示，判题不变；错满 3 次仍揭示正确键位。

会话顶栏显示进度数字、正确率、隐藏项与速度；统计胶囊内含暂停按钮与 `Shift+Space` 提示。

### 文章练习

1. **输入或导入**：粘贴文本，或点击 / 拖拽 `.txt`（UTF-8）；「输入」与「导入」共用同一份内容；
2. **解析**：只保留汉字；标点、字母、数字、空白与换行作为断行且不显示，每行最多 5 个汉字；拼音按上下文实时解析，无法映射到方案音节的汉字跳过，开始前提示「将练习 N 字 · 跳过 M 字」；
3. **练习**：按原文顺序逐字练习，无提示；隐藏候选为当前方案全部普通声母 / 韵母 / 零声母；
4. **汇总**：完成后在文章下方追加绿色汇总卡片，显示正确率、速度、错误次数、用时与错误键位排行；原文章内容保留，可「再来一遍」或「换文章」。

多音字按上下文分词级读音解析。

### 配置与预设

专项 / 文章页签、出现范围、焦点、专项隐藏与文章隐藏**按方案**保存在浏览器本地；三个选择卡都可通过右上角「清空」恢复空选择；损坏或缺失时回退为默认全选 / 不限焦点。课程练习中点击顶栏「进入练习」或按 `Alt+Enter`、或在阶段总结卡上点击「进入练习」，都会带入本课方案、全拼沿用与已学范围、本课焦点与阶段隐藏设置作为一次性预设，读取后立即清除。文章练习不使用焦点。

## 快捷键

页面级快捷键统一由输入管线注册；输入框、文本域、下拉框聚焦时不触发页面快捷键，只有 `Alt+T`、`Alt+B`、`Ctrl+K` / `Alt+K` 这类全局操作例外。`?` 打开快捷键面板，`Esc` 或 `?` 关闭。

### 全局

| 快捷键 | 作用 |
|---|---|
| `Alt+H` | 回到课程路线（学习地图） |
| `Alt+P` | 进入练习场 |
| `Alt+T` | 切换亮色 / 暗色主题 |
| `Alt+B` | 开启 / 关闭音效 |
| `Home` | 回到页面顶部；学习地图滚动超过 320px 后可用 |
| `Ctrl+K` / `Alt+K` | 显示 / 隐藏底部键位图 |
| `?` | 打开 / 关闭快捷键面板 |
| `Esc` | 关闭快捷键面板；或执行当前页面的一级返回 |

### 学习路线

| 快捷键 | 作用 |
|---|---|
| `Alt+S` | 聚焦当前双拼方案选择器 |
| `Alt+1` – `Alt+5` | 切换主要双拼方案 |
| `Alt+6` | 打开「更多方案」选择器 |
| `←` / `→` | 在方案按钮与「更多方案」下拉之间移动 |
| `↑` / `↓` | 在课程卡之间移动 |
| `Enter` | 开始当前课程 |
| `Alt+U` | 解锁全部课程 / 恢复锁定 |
| `Alt+C` | 清除当前方案的学习进度 |
| `Alt+L` | 定位到当前课程（滚动并高亮课程卡） |

### 教学页与入门课

| 快捷键 | 作用 |
|---|---|
| `Enter` | 开始练习 / 下一页 / 完成试打；有错误输入时优先清空 |
| `Alt+←` | 入门课返回上一页 |
| `Space` | 清空当前字的错误输入 |
| `Esc` | 返回学习路线 |

### 练习 / 考核

练习会话顶部的统计胶囊可点击暂停：暂停后输入与实时计时冻结，图标变为继续；再次点击或按 `Shift+Space` 恢复。暂停时在练习区覆盖显示中性色暂停卡片；练习场顶栏「结束练习」则在题目下方追加绿色结束卡片（课程练习不提供手动结束）。卡片统一显示统计、评分标准与错误键位（如有）；暂停恢复后回到原练习位置。

| 快捷键 | 作用 |
|---|---|
| `Enter` | 开始练习 / 下一阶段 / 完成本课；有错误输入时优先清空 |
| `Shift+Space` | 暂停 / 继续练习 |
| `Alt+Enter` | 进入练习（练习中或阶段总结卡出现后均可） |
| `Alt+←` | 上一阶段 |
| `Alt+R` | 重新开始当前阶段 |
| `Backspace` | 退格撤销当前输入 |
| `Space` | 清空当前字的错误输入 |
| `Esc` | 上一阶段；已在教学页时返回学习路线 |

### 练习场

| 快捷键 | 作用 |
|---|---|
| `Alt+D` / `Alt+A` | 切换专项 / 文章练习 |
| `Alt+1` – `Alt+5`、`Alt+6`、`←` / `→` | 切换方案 / 打开更多方案 / 移动 |
| `Enter` | 开始练习（焦点不在交互元素上时） |
| `Shift+Space` | 暂停 / 继续练习 |
| `Alt+E` | 结束练习 |
| `Esc` | 退出当前练习会话 / 返回练习场 / 换文章 |
| `Alt+R` | 重新开始当前会话 |
| `Space` / `Enter` | 清空当前字的错误输入 |
| `Backspace` | 退格撤销当前输入 |

### 通用

| 快捷键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 按顺序聚焦下一个 / 上一个控件 |
| `Enter` | 激活当前按钮 / 确认 |
| `Space` | 激活当前按钮 / 切换勾选 |

> 快捷键帮助数据在 `apps/web/src/lib/shortcuts.ts`，实际绑定由各页面的 `useGlobalKeys` 与 `useKeyInput` 负责。
