# 快捷键

[← 文档导航](../README.md#文档导航)

应用以键盘操作为主：`Enter` 主操作、`Esc` 返回 / 退出、`Alt+←` 上一级、`Alt+R` 重新开始。按 `?` 可随时打开应用内的完整快捷键面板。

## 快捷键面板

- 顶栏 `?` 按钮或键盘 `?` 打开面板；面板数据源是 `apps/web/src/lib/shortcuts.ts`，页面上的按键绑定分散在各页的 `useGlobalKeys` 中。
- 面板打开时会拦截页面快捷键并循环焦点；`Esc` 或 `?` 关闭，关闭后焦点回到打开前的元素。
- 面板按分组纵向依次排列，不再使用两列分组布局；每个分组内部用三列展示快捷键（窄屏依次降为两列 / 一列）。
- 方向键、`PageUp` / `PageDown`、`Home` / `End` 用于滚动画板内容，不会滚动下方页面。
- 输入框、文本域、下拉框、可编辑区域聚焦时，页面快捷键不会触发（`Alt+T`、`Alt+B`、`Ctrl+K`、`?` 等全局操作例外）。

面板内容（与应用内一致）：

### 全局

| 快捷键 | 作用 |
|---|---|
| `Alt+H` | 回到课程路线 |
| `Alt+P` | 进入练习场 |
| `Alt+T` | 切换亮色 / 暗色主题 |
| `Alt+B` | 开启 / 关闭音效 |
| `Home` | 回到页面顶部（学习路线滚动超过 320px 时可用） |
| `Ctrl+K` | 显示 / 隐藏底部键位图（兼容 `Alt+K`，仅在当前页面支持底部键位图时生效） |
| `?` | 打开 / 关闭快捷键面板 |
| `Esc` | 关闭面板或返回上一级 |

### 学习路线

| 快捷键 | 作用 |
|---|---|
| `Alt+S` | 聚焦当前双拼方案 |
| `Alt+1–5` | 切换主要双拼方案 |
| `Alt+6` | 打开「其他方案」选择器 |
| `←` / `→` | 在方案按钮 / 其他方案之间移动 |
| `↑` / `↓` | 在学习路线课程卡之间移动 |
| `Enter` | 开始当前课程 |
| `Alt+U` | 解锁全部课程 / 恢复锁定 |
| `Alt+C` | 清除当前方案进度 |

### 课程详情 / 入门课

| 快捷键 | 作用 |
|---|---|
| `Enter` | 开始练习 / 下一页 / 完成试打 |
| `Alt+←` | 返回上一页 |
| `Space` | 清空错误输入 |
| `Esc` | 返回路线 |

### 练习 / 考核

| 快捷键 | 作用 |
|---|---|
| `Enter` | 主操作（开始 / 下一阶段 / 完成本课） |
| `Alt+Enter` | 进入无尽练习（阶段结束后） |
| `Alt+←` | 上一阶段 |
| `Alt+R` | 重新开始当前阶段 |
| `Backspace` | 退格撤销当前输入 |
| `Space` | 清空错误输入 |
| `Esc` | 退出练习 |

练习中字母键与 `;` 直接作为输入；出现错误输入时 `Space` / `Enter` 清空当前字（`Enter` 清空优先于主按钮）。

### 练习场

| 快捷键 | 作用 |
|---|---|
| `Alt+D` | 专项练习 |
| `Alt+A` | 文章练习 |
| `Alt+M` | 字 / 词模式切换 |
| `Alt+1–5` | 切换主要双拼方案 |
| `Alt+6` | 打开「其他方案」选择器 |
| `←` / `→` | 在方案按钮 / 其他方案之间移动 |
| `Enter` | 开始练习 |
| `Alt+R` | 重新开始当前会话 |
| `Esc` | 结束练习会话 |

练习进行中同样使用字母 / `;`、`Backspace`、`Space`、`Esc`。

### 通用

| 快捷键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 按顺序聚焦下一个 / 上一个控件 |
| `Enter` | 激活当前按钮 / 确认 |
| `Space` | 激活当前按钮 / 切换勾选 |

## 设计约定

- 统一原则：`Enter` 主操作、`Esc` 返回 / 退出、`Alt+←` 上一级、`Alt+R` 重开；全局导航 `Alt+H` / `Alt+P`，主题 `Alt+T`，音效 `Alt+B`，底部键位图 `Ctrl+K`，帮助 `?`。
- 所有页面级快捷键必须通过 `useGlobalKeys` 注册，统一处理 IME 组合输入、长按重复与输入框例外，不允许直接 `window.addEventListener('keydown')`。
- 常用操作在按钮 / 标签上直接显示 `<kbd>` 提示：顶栏导航显示 `Alt+H` / `Alt+P`，方案按钮显示 `Alt+数字`，练习页签显示 `Alt+D` / `Alt+A`，阶段主操作显示 `Enter`。
- 未绑定专属快捷键的控件全部是原生按钮 / 勾选框 / 输入框，可用 `Tab` 聚焦、`Enter` / `Space` 激活。
- 仅指针点击（非键盘激活）后才清除按钮焦点，避免随后按 `Space` / `Enter` 误触刚点过的按钮；文本输入类控件保留焦点以继续编辑。

## 维护

修改快捷键时需要同步三处：

1. `apps/web/src/lib/shortcuts.ts`（应用内面板的展示数据）；
2. 对应页面 / composable 的 `useGlobalKeys` 绑定（实际行为）；
3. 本页面的表格。

实现细节与测试约定见 [架构说明](ARCHITECTURE.md)，按键提示的视觉规范见 [界面与设计](UI.md)。
