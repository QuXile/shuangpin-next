# 快捷键

[← 文档导航](../README.md#文档导航)

`Enter` 主操作、`Esc` 返回 / 退出、`Alt+←` 上一级、`Alt+R` 重新开始。按 `?` 打开应用内快捷键面板（`Esc` / `?` 关闭）。输入框、文本域、下拉框聚焦时页面快捷键不触发，`Alt+T`、`Alt+B`、`Ctrl+K`、`?` 等全局操作例外。

## 全局

| 快捷键 | 作用 |
|---|---|
| `Alt+H` | 回到课程路线 |
| `Alt+P` | 进入练习场 |
| `Alt+T` | 切换亮色 / 暗色主题 |
| `Alt+B` | 开启 / 关闭音效 |
| `Home` | 回到页面顶部（学习路线滚动超过 320px 时可用） |
| `Ctrl+K` | 显示 / 隐藏底部键位图（兼容 `Alt+K`，仅支持底部键位图的页面生效） |
| `?` | 打开 / 关闭快捷键面板 |
| `Esc` | 关闭面板或返回上一级 |

## 学习路线

| 快捷键 | 作用 |
|---|---|
| `Alt+S` | 聚焦当前双拼方案 |
| `Alt+1–5` | 切换主要双拼方案 |
| `Alt+6` | 打开「其他方案」选择器 |
| `←` / `→` | 在方案按钮 / 其他方案之间移动 |
| `↑` / `↓` | 在学习路线课程卡之间移动 |
| `Enter` | 开始当前课程 |
| `Alt+U` | 解锁全部课程 / 恢复锁定 |
| `Alt+C` | 清除当前方案进度 |

## 课程详情 / 入门课

| 快捷键 | 作用 |
|---|---|
| `Enter` | 开始练习 / 下一页 / 完成试打 |
| `Alt+←` | 返回上一页 |
| `Space` | 清空错误输入 |
| `Esc` | 返回路线 |

## 练习 / 考核

| 快捷键 | 作用 |
|---|---|
| `Enter` | 主操作（开始 / 下一阶段 / 完成本课） |
| `Alt+Enter` | 进入无尽练习（阶段结束后） |
| `Alt+←` | 上一阶段 |
| `Alt+R` | 重新开始当前阶段 |
| `Backspace` | 退格撤销当前输入 |
| `Space` | 清空错误输入 |
| `Esc` | 退出练习 |

练习中字母键与 `;` 直接输入；有错误输入时 `Space` / `Enter` 清空当前字（`Enter` 优先于主按钮）。

## 练习场

| 快捷键 | 作用 |
|---|---|
| `Alt+D` | 专项练习 |
| `Alt+A` | 文章练习 |
| `Alt+M` | 字 / 词模式切换 |
| `Alt+1–5` | 切换主要双拼方案 |
| `Alt+6` | 打开「其他方案」选择器 |
| `←` / `→` | 在方案按钮 / 其他方案之间移动 |
| `Enter` | 开始练习 |
| `Alt+R` | 重新开始当前会话 |
| `Esc` | 结束练习会话 |

训练进行中同样使用字母 / `;`、`Backspace`、`Space`、`Esc`。

## 通用

| 快捷键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 按顺序聚焦下一个 / 上一个控件 |
| `Enter` | 激活当前按钮 / 确认 |
| `Space` | 激活当前按钮 / 切换勾选 |
