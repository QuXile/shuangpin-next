# 学习指南

[← 文档导航](../README.md#文档导航)

课程假定你已经会拼音（声母、韵母、声调），只教双拼的键位差异。练习场的自由练习见[练习场](TRAINING.md)，按键见[快捷键](SHORTCUTS.md)。

## 学习路线

当前五套课程采用「入门 → 新课 → 复习 → 期中 / 综合 → 通关」的结构。

- **一课一键**：每次只引入新的声母或韵母；同键双韵（如 `ia/ua`、`ong/iong`、`ue/ve`）合并成一课。
- **复习范围程序化生成**：复习课直接复用此前已学知识点，按学习顺序展示。
- **零声母单独成课**：零声母音节在一课内集中教学，标签统一显示为「零 ai」这类形式。

其余 14 套仅支持练习：学习路线只显示占位说明与键位图，可在练习场直接练习。

## 课型与练习阶段

除入门课外，进入课程先看教学页，再按课型练习。**单位统一为词**（逐字练习时 1 个字 = 1 个词），每课最后一场都是全遮挡考核。

| 课型 | 阶段（提示档位） | 最低完成量 |
|---|---|---|
| 新课 | 单字（全显）→ 词语（半遮挡）→ 全遮挡考核 | 15 → 15 → 25 词 |
| 复习（含家族复习 / 期中 / 综合） | 全遮挡练习 / 考核 | 50 词 |
| 通关 | 全遮挡考核 | 100 词 |

单字 / 词语阶段只要求完成最低词数；全遮挡考核还需达到本课通过标准，达标后自动记录通过。每阶段结束出现总结卡：达标绿色、未达标红色（展示原因、错误键位与评分），可重新开始；已达标阶段保持解锁，来回切换不需要重练。

## 评分与星级

1–3 星，**1 星即最低通过标准**；「未揭示答案」指本阶段没有错满三次而显示正确键位。

| 课程 | ★ | ★★ | ★★★ |
|---|---|---|---|
| 入门 | 完成试打 | 同 ★ | 完成试打即记 ★★★ |
| 新课（25 词全遮挡） | 正确率 ≥85% | ≥90% | ≥95% 且未揭示答案 |
| 复习 / 期中·混合 / 综合·混合（50 词） | ≥85% 且速度 ≥45 WPM | ≥90% 且 ≥45 WPM | ≥95%、≥45 WPM 且未揭示答案 |
| 期中 / 综合速度（50 词） | ≥85% 且 ≥45 WPM | ≥85% 且 ≥60 WPM | ≥85% 且 ≥75 WPM |
| 通关考核（100 词） | ≥85% 且 ≥45 WPM | ≥90% 且 ≥60 WPM | ≥95%、≥75 WPM 且未揭示答案 |

已通过的课程可重练，尝试次数、最佳正确率与星级都取历史最优。

## 进度与解锁

- 课程按顺序解锁：前一课通过后解锁下一课；已通过课程可重练。
- 「解锁全部课程」（`Alt+U`）解除全部顺序限制并持久化，再次触发变为「恢复锁定」。
- 「清除进度」（`Alt+C`）只清当前方案的学习记录，不影响解锁标记。
- 进度按方案分开保存。

## 入门课

独立的 5 步组件：全拼成本 → 五套课程方案与选择建议 → 双拼原理与键位图 → 与全拼重合的键位 → 试打「双拼」。原理页合并了键位图读法与记忆策略（改造声母 / 韵母 / 零声母、同键叠层），全拼沿用页单独列出本方案仍与全拼一致的声母、韵母与零声母。键位与示例由当前方案引擎生成；完成试打并写入通过记录，统一记 ★★★。底部键位图从第一页起固定在页面最下方，可用 `Ctrl+K` 隐藏。

## 教学页

- **课程范围**：本课要学的键位知识点（含零声母）及映射数量。
- **示例**：按本课 focus 原子枚举所有相关音节，每个音节一张高频代表字卡片。
- **记忆锚点（键位技巧）**：只在新课出现；零声母全表课为一条汇总行；复习 / 考核课不显示。
- **本课技巧**：每课 1–4 条文字提示。
- **评分标准**：与判定同源的星级与门槛说明。

## 输入与错误处理

- 合法输入键为小写字母与 `;`；输入完当前字后整字判题（多解容错）。
- 判错后保留红色错误输入并锁定该字，继续按字母无反应；退格逐键撤销并解除错误。
- 空格或 `Enter` 一次清空当前字错误输入，`Enter` 清空优先于主按钮。
- 同一个字错满 3 次直接揭示目标键位。正确率 = 正确字数 /（正确字数 + 错误次数），速度按正确字数 / 用时计算。

## 学习地图

- **Hero**：右侧键帽由当前方案名称逐字取拼音再映射成按键，随机散落，可用键盘或点击键位图按顺序输入；答对变绿，部分答对后闲置 8 秒会重新散落。
- **方案选择**：Hero 展示 5 套课程方案（`Alt+1–5`），其余收进「其他方案」（`Alt+6`）；`Alt+S` 聚焦方案，`←/→` 在方案按钮与选择器之间移动。
- **继续学习与路线**：继续学习卡显示当前课并可开始；路线按章节分组、两列课程卡；`↑/↓` 选课、`Enter` 开始，已通过课程显示星级。
- **滚动与回顶**：滚动位置按方案记忆；滚动超过 320px 后右下角出现「回到顶部」按钮（`Home`）。
- **学习进度卡**：显示完成百分比、通过课程数、章节数与课程词汇数，卡头为「清除进度 / 解锁全部课程」。
