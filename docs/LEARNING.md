# 学习指南

[← 文档导航](../README.md#文档导航)

课程假定你已经会拼音（声母、韵母、声调），只教双拼的键位差异。练习场的自由练习见[练习场](TRAINING.md)，按键见[快捷键](SHORTCUTS.md)。

## 学习路线

19 套课程都采用「入门 → 新课 → 复习 → 期中 / 综合 → 通关」的结构：5 套为手写完整课程，14 套为按方案数据自动生成的通用课程。

- **一课一键**：每次只引入新的声母或韵母。5 套手写课程会把同键双韵（如 `ia/ua`、`ong/iong`、`ue/ve`）合并成一课；14 套通用课程按单个原子逐课教学、不合并。
- **复习范围程序化生成**：复习课直接复用此前已学知识点，按学习顺序展示。
- **零声母**：手写课程在一课内集中教学 12 个音节；通用课程逐个零声音节单独成课，标签统一显示为「零 ai」这类形式。
- **通用课程结构**：第一章「入门」= 通用入门 + 全拼沿用复习（与全拼一致的键位）；内容章按「单韵母 → 单声母 → 复合声母 → 前响 / 后响 / 中响复韵母 → 基本 / 带介前鼻、后鼻韵母 → 零声母」排列，每章末复习；内容章之间按前后新课数均衡自动插入「期中」；最终章为综合练习 → 速度练习 → 最终考核。推荐码例外与兼容编码信息写在对应原子课的技巧里。

## 课型与练习阶段

除入门课外，进入课程先看教学页，再按课型练习。**单位统一为词**（逐字练习时 1 个字 = 1 个词），每课最后一场都是无提示考核。

| 课型 | 阶段（提示档位） | 最低完成量 |
|---|---|---|
| 新课 | 单字（完整提示）→ 词语（部分提示）→ 无提示考核 | 15 → 15 → 25 词 |
| 复习（含家族复习 / 期中 / 综合） | 无提示练习 / 考核 | 50 词 |
| 通关 | 无提示考核 | 100 词 |

单字 / 词语阶段只要求完成最低词数；无提示考核还需达到本课通过标准，达标后自动记录通过。每阶段结束出现总结卡：达标绿色、未达标红色（展示原因、错误键位与评分），可重新开始；已达标阶段保持解锁，来回切换不需要重练。

## 评分与星级

1–3 星，**1 星即最低通过标准**；「未揭示答案」指本阶段没有错满三次而显示正确键位。

| 课程 | ★ | ★★ | ★★★ |
|---|---|---|---|
| 入门 | 完成试打 | 同 ★ | 完成试打即记 ★★★ |
| 新课（25 词无提示） | 正确率 ≥85% | ≥90% | ≥95% 且未揭示答案 |
| 复习 / 期中·混合 / 综合·混合（50 词） | ≥85% 且速度 ≥45 WPM | ≥90% 且 ≥45 WPM | ≥95%、≥45 WPM 且未揭示答案 |
| 期中 / 综合速度（50 词） | ≥85% 且 ≥45 WPM | ≥85% 且 ≥60 WPM | ≥85% 且 ≥75 WPM |
| 通关考核（100 词） | ≥85% 且 ≥45 WPM | ≥90% 且 ≥60 WPM | ≥95%、≥75 WPM 且未揭示答案 |

已通过的课程可重练，尝试次数、最佳正确率与星级都取历史最优。

## 进度与解锁

- 课程按顺序解锁：前一课通过后解锁下一课；已通过课程可重练。
- 「解锁全部课程」（`Alt+U`）解除全部顺序限制并持久化，再次触发变为「恢复锁定」。
- 「清除进度」（`Alt+C`）只清当前方案的学习记录，不影响解锁标记。
- 进度按方案分开保存。

## 入门课

自动生成的通用入门课：拼音基础 → 声母 → 韵母 → 零声母 → 多键（本方案有多键时）→ 推荐码 / 兼容编码（本方案有此类编码时）→ 工具说明 → 试打。键位、示例与试打词由当前方案引擎和统一词表生成，不写死方案名；完成试打并写入通过记录，统一记 ★★★。底部键位图从第一页起固定在页面最下方，可用 `Ctrl+K` 隐藏。

## 教学页

- **课程范围**：本课要学的键位知识点（含零声母）及映射数量。
- **示例**：按本课 focus 原子枚举所有相关音节，每个音节一张高频代表字卡片。
- **记忆锚点（键位技巧）**：只在新课出现；复习 / 考核课不显示。手写课程的零声母全表课为一条汇总行；通用课程的零声母逐音节成课，不显示汇总行。
- **本课技巧**：每课 1–4 条文字提示；通用课程含推荐码 / 兼容编码信息时会分块追加（C 双拼等方案最多约 10 条）。
- **评分标准**：与判定同源的星级与门槛说明。

## 输入与错误处理

- 合法输入键为小写字母与 `;`；输入完当前字后整字判题（多解容错）。
- 判错后保留红色错误输入并锁定该字，继续按字母无反应；退格逐键撤销并解除错误。
- 空格或 `Enter` 一次清空当前字错误输入，`Enter` 清空优先于主按钮。
- 同一个字错满 3 次直接揭示目标键位。正确率 = 正确字数 /（正确字数 + 错误次数），速度按正确字数 / 用时计算。

## 学习地图

- **Hero**：右侧键帽由当前方案名称逐字取拼音再映射成按键，随机散落，可用键盘或点击键位图按顺序输入；答对变绿，部分答对后闲置 8 秒会重新散落。
- **方案选择**：Hero 下方为方案按钮，点击或用 `Alt+数字` 切换课程方案；方案较多时其余方案收进「其他方案」（`Alt+6`）。`Alt+S` 聚焦方案，`←/→` 在方案按钮与选择器之间移动。
- **继续学习与路线**：继续学习卡显示当前课并可开始；路线按章节分组、两列课程卡；`↑/↓` 选课、`Enter` 开始，已通过课程显示星级。
- **滚动与回顶**：滚动位置按方案记忆；滚动超过 320px 后右下角出现「回到顶部」按钮（`Home`）。
- **学习进度卡**：显示完成百分比、通过课程数、章节数与课程词汇数，卡头为「清除进度 / 解锁全部课程」。
