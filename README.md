# 双拼 NEXT

给已经熟练全拼、想学双拼的人：一条从「认识键位」到「能真的打字」的完整学习路线。

在线体验：<https://quxile.github.io/shuangpin-next/> · 版本 1.6.6

如果这个项目对你有帮助，欢迎在 [GitHub](https://github.com/QuXile/shuangpin-next) 点一个 **Star**；遇到问题或有课程 / 键位上的建议，欢迎直接开 [Issue](https://github.com/QuXile/shuangpin-next/issues)。

## 想解决的痛点

学双拼最难的一步，往往不是“键位太多”，而是**把键位图当成密码表硬背**：

- 看教程时觉得懂了，关掉教程只剩一张图；
- 背了几个声母韵母，没有题目能练，背完就忘；
- 单词 / 文章练习一上来全是生键，跟不上，最后卡在“没背完”和“练不下去”之间。

双拼 NEXT 把这件事拆成一条可执行的学习路线：**每课只引入一个到几个新键位，题目只使用已经学过的内容**，从单字、词语到无提示考核，再到真实文章。键位不是背完才用，而是在每次练习里逐步变成手指记忆。

## 特点

- **循序渐进，不要求先背完整张图**：新课一次只学一个声母或韵母（定制课程会把同键双韵合并成一课），题目只包含已学键位；课程按「入门 → 新课 → 复习 → 期中 / 综合 → 通关」自动推进。
- **专门为“练下去”设计**：每课固定「单字完整提示 → 词语部分提示 → 无提示考核」，提示逐档撤掉，不会一上来就要求盲打。
- **学习内容来自真实词频**：内置 50,000 条离线词语 + 3,272 个单字，优先使用高频词和日常词汇；同一个知识点随机出题，避免背答案，也更接近实际输入。
- **学完能用在真实文本上**：练习场支持专项词语练习和文章练习，可以粘贴或导入 `.txt`，按上下文逐字解析拼音；专项还可以设置「焦点」，要求每个词至少包含一个目标键位。
- **19 套双拼方案**：小鹤、微软、自然码、拼音加加、搜狗有定制课程，其余主流方案与 C、键道、大牛等特色方案提供按方案数据生成的通用路线；所有方案共用同一套判题、键位图与练习场。
- **纯前端、离线可用**：没有账号与云同步，进度和设置只保存在浏览器本地；提供带启动器的静态包，断网也能学。词表在构建期预解析，进入练习只需解码紧凑数据，不再在浏览器里逐词解析拼音。
- **细节齐全**：声母 / 韵母分色键位图、同键分组、零声母与兼容编码展示、亮暗主题、合成音效、完整快捷键。

## 适合谁

- 已经会用全拼，想系统学一门双拼，但不知道从哪里开始、怎么坚持；
- 已经在用某个双拼方案，想把键位、零声母和兼容编码补扎实；
- 想换方案，或者只想用练习场自由练词语 / 文章，不跟课程进度；
- 希望数据离线可用、不注册账号、不依赖系统输入法。

| 类型 | 方案 |

| 通用课程 | 智能 ABC、紫光双拼、蓝天双拼、白云双拼、小月双拼、国标双拼、开源小鹳、小浪双拼、韵标块拼、星空双拼、大牛双拼、键道双拼 3、键道双拼 6、C 双拼 |

## 学习路线是怎么组织的

- **入门课**：按当前方案生成拼音基础、方案选择、声母、韵母、零声母、多键与推荐码说明，并固定试打「双拼」；
- **新课**：每次只引入一个到几个新键位，先看教学页，再依次完成单字、词语、无提示考核；
- **复习 / 期中 / 综合**：章末复习只覆盖本章刚学的键位，期中 / 综合复用累计范围，难度逐步提高；
- **最终考核**：综合练习 → 速度练习 → 通关考核，正确率与速度同时达标才算通关；
- **进度与解锁**：前一课通过后解锁下一课；已通过课程可重练，星级与最佳正确率取历史最优；`Alt+U` 可解锁全部课程；
- **章节折叠**：点击章节头可展开 / 收起该章课程，状态按方案保存；整章首次学完会自动收起一次，之后保留你的选择；定位当前课时自动展开所在章节。

课型、阶段与星级规则见[使用说明](docs/USAGE.md#学习路线与课程)。

## 快速开始

- **在线使用**：<https://quxile.github.io/shuangpin-next/>，无需安装；
- **离线静态包**：从 [GitHub Releases](https://github.com/QuXile/shuangpin-next/releases) 下载 `shuangpin-next-<版本>-static.zip`，解压后运行 `python start.py`，详见[使用说明](docs/USAGE.md)；
- **本地开发**（Node.js ≥ 24、pnpm 11.28.5）：

  ```bash
  pnpm install --frozen-lockfile
  pnpm dev        # http://127.0.0.1:5199
  ```

## 已知限制

- **只支持纯双拼**：编码模型为「声母 + 韵母」，不包含汉字形码、拆字规则与候选窗，也不接入系统输入法；
- **多音字按词解析**：词语按词内读音、文章按上下文分词级读音解析；`ng` 等不在方案音节内的读音在文章练习中跳过；
- **进度仅保存在浏览器本地**：没有账号与云同步，清除站点数据、换浏览器或换设备后不会迁移。
