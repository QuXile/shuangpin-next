# 双拼 NEXT

> 版本 1.2.0 · 在线体验：<https://quxile.github.io/shuangpin-next/>

给已经会用全拼、想学会双拼的人：把「学键位 → 练单字 → 练词语 → 无提示考核」串成一条线的双拼练习应用。课程之外还有自由练习场，支持 19 套双拼方案、亮 / 暗主题、可开关的合成音效与完整键盘快捷键。

欢迎在 GitHub 上 **Star** 本项目，也欢迎通过 Issues 提出问题与建议：<https://github.com/QuXile/shuangpin-next>。

## 适合谁

- 会全拼，想学双拼但一直被键位表劝退的人；
- 学过双拼，但长期不用、想重新捡起来的人；
- 想每天练十分钟、需要明确进度和反馈的人。

## 它能解决什么问题

- **一次只学一个键位**：每课只引入一个新声母或韵母，出的题只包含已学内容，学过的键位自动出现在后续练习里。
- **每课随机出题**：同样的知识点，每次练到的字词不同，避免背题。
- **用日常词汇练真实打字**：课程与练习场共用一套 26,883 词 / 5,022 字的统一词表，按已学范围和当前选择筛选。
- **先单字、再词语、最后不看提示**：新课先熟悉键位，再用常用词模拟打字，最后隐藏全部提示检验水平。
- **打错不卡死**：保留错误输入并提醒，可逐键退回或一次清空；同一个字错三次直接显示答案。
- **评分与进度清楚**：按正确率和速度给 1–3 星，1 星即通过；历史最佳成绩不会被之后的较差尝试覆盖。

## 核心功能

- **40 课结构化路线**：10 章、约 326 分钟；入门 / 新课 / 复习 / 通关依次推进，穿插期中与综合。
- **三档提示**：单字全显 → 词语半遮挡 → 全遮挡考核，每课最后一场都是全遮挡。
- **19 套双拼方案**：覆盖常见双拼方案。
- **学习路线地图**：Hero 键帽、继续学习、键位图、学习进度与章节路线集中在一屏。
- **自由练习场**：专项（选声母 / 韵母 / 零声母、字或词、可隐藏提示）与文章（粘贴或导入 `.txt`）练习，不限目标行数。
- **键位图与键帽**：课程、练习场、底部 Dock 共用键位图，带零声母行、改造声母标记与按下 / 高亮反馈。
- **亮 / 暗主题与轻量音效**：跟随系统或手动切换；键盘、错误、完成音效由 Web Audio 合成，可随时开关。
- **纯前端、无账号**：进度与设置只保存在浏览器本地，另有可离线使用的静态包。

## 学习路线概览

40 课 / 10 章，约 326 分钟：

| 章 | 主题 | 内容 |
|---|---|---|
| 01 | 认识双拼 | 原理 + 键位图 + 试打「双拼」 |
| 02 | 声母与零声母 | zh / ch / sh、零声母 12 音全表与复习 |
| 03 | a 家族 | ai / ao / an / ang、介音组与同键双韵、家族复习 |
| 04 | o 家族 | uo / ou / ong·iong 与复习 |
| 05 | 期中检验 | 混合练习 + 速度练习 |
| 06 | e 家族 | ei / en / eng 与家族复习 |
| 07 | i 家族 | in / ing / ie / iu 与家族复习 |
| 08 | u 与 ü 家族 | ui / un / ü·üe / ve 与家族复习 |
| 09 | 综合冲刺 | 全量混合 + 速度冲刺 |
| 10 | 通关考核 | 全遮挡 + 限时通关 |

课型、阶段、星级与进度规则见[学习指南](docs/LEARNING.md)。

## 双拼方案概览

- **带完整课程的 5 套**：小鹤双拼（默认）、自然码、微软双拼、搜狗双拼、智能 ABC。
- **纯练习的 14 套**：拼音加加、紫光双拼、蓝天双拼、白云双拼、小月双拼、国标双拼、开源小鹳、小浪双拼、韵标块拼、星空双拼、大牛双拼、键道双拼 3、键道双拼 6、C 双拼。

## 快速开始

- **在线使用**：打开 <https://quxile.github.io/shuangpin-next/>，无需安装。
- **下载静态包离线使用**：在 [GitHub Releases](https://github.com/QuXile/shuangpin-next/releases) 下载 `shuangpin-next-<版本>-static.zip`，解压后运行 `python start.py`，见[使用说明](docs/USAGE.md)。
- **本地开发**（Node.js ≥ 24、pnpm 11.28.5）：

  ```bash
  pnpm install --frozen-lockfile
  pnpm dev        # http://127.0.0.1:5199
  ```

  其他命令与提交前检查见[贡献指南](docs/CONTRIBUTING.md)。
