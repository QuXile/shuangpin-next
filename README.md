# 双拼 NEXT

> 版本 1.1.0 · 在线体验：<https://quxile.github.io/shuangpin-next/>

给已经会用全拼、想学会双拼的人：把「学键位 → 练单字 → 练词语 → 无提示考核」串成一条线的双拼练习应用。课程之外还有自由练习场，支持 19 套双拼方案、亮 / 暗主题、可开关的合成音效与完整键盘快捷键。

如果这个项目对你有帮助，欢迎在 GitHub 上 **Star**，也欢迎通过 Issues 提出问题与建议：<https://github.com/QuXile/shuangpin-next>。

## 适合谁

- 会全拼，想学双拼但一直被键位表劝退的人；
- 学过双拼，但长期不用、想重新捡起来的人；
- 想找一个能每天练十分钟、有明确进度和反馈的练习工具的人。

不需要注册账号。学习进度、主题、音效与练习配置都只保存在你自己的浏览器里。

## 它能解决什么问题

双拼要记的键位很多。大多数教程一次把一整张键位表推给你，结果往往是一开始觉得信息量太大、勉强背了却不知道该练什么、练习题固定不变，学到后面又忘了前面。双拼 NEXT 把这些拆开处理：

- **一次只学一个键位，学过内容自动变成复习**。每一课只引入一个新声母或韵母；每次出的题只包含已经学过的内容，刚学完就能立刻开始打。后面的课程里，学过的键位会自然出现在新练习中，不必单独回头「补课」。
- **每一课都随机出题**。同样的知识点，每次练到的字词都不一样，避免记住某几道题。
- **用日常词汇练真实打字**。词汇来自日常常用词，新课每课上限 500 词、复习 / 考核每课上限 1000 词，40 课合计 26,000 条课次；另补充三字词、四字成语与五字词，减少撞题，也更接近日常输入。
- **先单字，再词语，最后不看提示考核**。新课先熟悉键位，再用常用词模拟日常打字，最后隐藏全部提示检验真实水平。
- **打错不会卡死，也不会让你蒙混过去**。打错保留输入并提醒；可逐键退回，也可一次清空重来；同一个字错三次会直接显示答案，保证练得下去。
- **每课都有清楚的评分**。按正确率和速度给 1–3 星，1 星即最低通过标准；通过即记录，星级、正确率等历史最佳成绩不会被之后较差的尝试覆盖。
- **全程可以不用鼠标**。`?` 打开完整快捷键面板，`Ctrl+K` 显示 / 隐藏底部键位图，`Alt+H` / `Alt+P` 切换板块，常用操作旁直接标出快捷键。

## 核心功能

- **40 课结构化路线**：10 章、约 326 分钟；1 节入门 + 27 节新课 + 11 节复习 / 检验 + 1 节通关，先教键位、再穿插复习与速度练习，最后用混合内容检验。
- **三档提示**：单字全显 → 词语半遮挡 → 全遮挡考核；每一课最后一场都是全遮挡。
- **19 套双拼方案**：5 套带完整课程（小鹤、自然码、微软、搜狗、智能 ABC），其余 14 套为纯练习方案；方案数据驱动，不把某一套方案的键位硬编码进逻辑。
- **学习路线地图**：Hero 键帽、继续学习、键位图、学习进度与章节路线集中在一屏；支持解锁全部课程、清除进度、按方案记忆滚动位置。
- **自由练习场**：专项练习（选声母 / 韵母 / 零声母音节、字或词、可隐藏提示）与文章练习（粘贴或导入 `.txt`，逐字练习），不限目标行数，练到主动退出。
- **键位图与键帽**：课程、练习场、底部 Dock 共用同一套键位图；带零声母独立行、改造声母标记、按下 / 高亮反馈；Hero 键帽随机散落并可输入。
- **亮 / 暗主题与轻量音效**：跟随系统或手动切换；键盘、错误、完成音效由 Web Audio 合成，可随时开关。
- **纯前端、无账号**：进度与设置保存在浏览器本地；同时提供可离线的静态包。

## 学习路线概览

40 课 / 10 章，约 326 分钟：

| 章 | 主题 | 内容 |
|---|---|---|
| 01 | 认识双拼 | 原理 + 键位图 + 试打「双拼」 |
| 02 | 声母与零声母 | zh / ch / sh、零声母 12 音全表与复习 |
| 03 | a 家族 | ai / ao / an / ang，介音组与同键双韵，家族复习 |
| 04 | o 家族 | uo / ou / ong·iong 与复习 |
| 05 | 期中检验 | 混合练习 + 速度练习 |
| 06 | e 家族 | ei / en / eng 与家族复习 |
| 07 | i 家族 | in / ing / ie / iu 与家族复习 |
| 08 | u 与 ü 家族 | ui / un / ü·üe / ve 与家族复习 |
| 09 | 综合冲刺 | 全量混合 + 速度冲刺 |
| 10 | 通关考核 | 全遮挡 + 限时通关 |

完整课表、三阶段与星级规则、入门课流程、进度与解锁说明见 **[学习指南](docs/LEARNING.md)**。

## 双拼方案概览

- **带完整课程的 5 套**：小鹤双拼（默认）、自然码、微软双拼、搜狗双拼、智能 ABC。
- **纯练习 14 套**：拼音加加、紫光双拼、蓝天双拼、白云双拼、小月双拼、国标双拼、开源小鹳、小浪双拼、韵标块拼、星空双拼、大牛双拼、键道双拼 3、键道双拼 6、C 双拼。

方案选择在**全站共享**：从学习路线 Hero 或练习场品牌卡切换后，两边统计的是同一个当前方案。切到纯练习方案时，学习路线进入预览模式（显示占位说明与完整键位图，无课程与进度），练习场可直接练；预览方案不写入持久化，刷新后回到上次保存的课程方案。方案行为与键位差异见 **[学习指南](docs/LEARNING.md)**，方案数据口径见 **[数据说明](docs/DATA.md)**。

## 快速开始

- **在线使用**：打开 <https://quxile.github.io/shuangpin-next/>，无需安装。
- **下载静态包离线使用**：在 [GitHub Releases](https://github.com/QuXile/shuangpin-next/releases) 下载 `shuangpin-next-<版本>-static.zip`，解压后运行 `python start.py`。详见 [使用说明](docs/USAGE.md)。
- **本地开发**（需要 Node.js ≥ 24 与 pnpm 11.28.5）：

  ```bash
  pnpm install --frozen-lockfile
  pnpm dev        # http://127.0.0.1:5199
  ```

  完整环境、命令与提交前检查见 [贡献指南](docs/CONTRIBUTING.md)。
